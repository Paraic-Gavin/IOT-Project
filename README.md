The Smart Classroom Energy Saver is an IoT-based system to avoid wasting energy in the classroom. 
The system utilizes an ESP32 microcontroller, a PIR motion sensor, a DHT11 temperature and humidity sensor, and a 4-channel relay module to automatically control classroom appliances, including lights and buzzers.
When motion is detected, the system switches the classroom light on automatically. If no movement is found for a set period, then the light turns off to conserve energy. 
The same system reads temperature and humidity and displays all the sensor data on a web page hosted by the ESP32.

Features:

Automatic light control using PIR motion detection
Temperature and humidity monitoring using DHT11
Remote monitoring through a web server
Manual appliance controls through webpage buttons
Energy-saving automation using IoT technology
